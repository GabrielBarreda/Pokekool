# Pokekool Web Frontend

Le front React sera créé ici.

## Stack prévue
- **Vite** + **React** + **TypeScript**
- TailwindCSS
- React Query pour les appels API
- React Router v6

## Démarrage (à venir)

```bash
npm create vite@latest pokekool-web -- --template react-ts
cd pokekool-web
npm install
npm run dev
```

> Le dossier `poke-web/` (Angular) n'est plus utilisé et sera supprimé.
