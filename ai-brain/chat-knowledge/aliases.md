# Aliases et raccourcis métier

Ce fichier aide le LLM à résoudre les alias courants en noms de sets ou de cartes.

## Sets Pokémon — raccourcis fréquents
- "151" → "Scarlet & Violet 151"
- "SV151" → "Scarlet & Violet 151"
- "EVA" → "Évolutions à Paldea"
- "PAF" → "Paldea Evolved"
- "OBF" → "Obsidian Flames"
- "MEW" → "Scarlet & Violet 151"
- "base" → "Base Set"
- "jungle" → "Jungle"
- "fossil" → "Fossil"
- "neo genesis" → "Neo Genesis"

## États de carte (codes techniques → libellé FR affiché)
Le code reste la valeur stockée ; on n'affiche que le libellé français.
- "NM" → "Neuf"
- "LP" → "Très bon"
- "MP" → "Bon"
- "HP" → "Usé"
- "DMG" → "Abîmé"

## Produits scellés courants
- "ETB" → "Elite Trainer Box"
- "booster box" → boîte de 36 boosters
- "tin" → boîte métal

## Types de produit (enum ShopProductType)
- "CardRaw" → carte brute (non gradée)
- "CardGraded" → carte gradée (PSA/BGS/CGC)
- "SealedSet" → produit scellé (booster box, ETB…)
- "SealedUpc" → produit scellé identifié par code-barres UPC
