# Symboles de sets — Identification visuelle des extensions Pokémon TCG

Les symboles de sets sont de petits logos imprimés en bas à droite du numéro de carte. Ils permettent d'identifier l'extension même sans lire le texte. Ce fichier est organisé par ère.

## Sets Japonais uniquement

Certaines cartes viennent de sets exclusivement japonais avant exportation internationale. Indices :
- Texte japonais sur la carte
- Symboles de sets non listés ci-dessus
- Format légèrement différent (souvent plus de détails d'artwork)

## Conseils pour le LLM

1. Le symbole de set est **très petit** (2–3mm sur la carte physique) — il peut être flou en photo
2. En cas de doute sur le symbole, **utiliser les indices visuels de l'ère** (style artwork, mécanique de jeu visible, bordure de carte)
3. Le nom du set imprimé sur les étiquettes de slab est souvent le nom court anglais
4. Si la carte est en japonais, le set peut ne pas avoir d'équivalent international exact — signaler dans `setName`
